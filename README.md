Logical gates editor for Gunsaw/MP
Lets you build logical schemes and then export into gunsaw/mp level

Features:
 - All logical gates in Gunsaw/MP
 - 1:1 Simulation within the editor
 - Automaticly step on each frame or use space to advance one tick
 - Right click gate/wire to delete
 - Left click to drag gate and interact with button
 - Zoom on mouse wheel
 - Save/load feature
 - Ctrl-Alt-Shift-O to open save directory
 - Export into valid gunsaw level
 - Repaintable lamp
 - Hold Shift while selecting gate to swap it
 - Multiplue input 1 output OR Multiple outputs 1 input, if multiple outputs to same input is high simulation halts; MIMO is forbiden as cant be reliable exported
 - Selection tool to move/delete multiple gate
 - While having selection, press Ctrl-D to duplicate all gates and connections within them
 - Ctrl-Shift-D to also duplicate outputs
 - Physical mode in which triggers are hidden and you place tiles so you dont have to recreate everything from scratch on each export
 - Clock IN/Clock OUT components, that are just expanded to wire from clock in to all clock outs on export; there to keep your project a bit more clean
 - Multiple save slots
 - Ctrl-Z to undo the last edit (up to 100 edits)
